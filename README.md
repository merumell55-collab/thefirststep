# The First Step

GDevelop 5 で作る、PC 向けの見下ろし型 2D RPG の初期プロジェクトです。
公式の **Top Down RPG** サンプルを土台にしています。
移動・会話・カメラ・簡単な戦闘のイベントと素材が含まれています。
通信機能は前提にしていません。捕獲・育成・セーブは今後の開発対象です。

## 開く方法

1. https://gdevelop.io/ から無料のデスクトップ版をインストールします。
2. このリポジトリを PC にダウンロードし、ZIP の場合は展開します。
3. GDevelop の既存プロジェクトを開く機能で `game.json` を選びます。
4. `Overworld` シーンを開き、プレビューを実行します。

`game.json` と `assets/`、`thumbnail.png` は同じフォルダーに置いてください。
この初期プロジェクトには npm、Godot、API キーは不要です。

## 最初の動作確認

- 矢印キーで移動できること。
- NPC の近くで E キーを押し、会話を進められること。
- サンプルの戦闘導線から `Battle` シーンを確認できること。

公式サンプルの表示・会話は英語です。日本語化は次の開発で行えます。
クラウド側では JSON と素材参照を確認していますが、GDevelop の画面上での
プレビュー、操作、PC 向けビルドは未検証です。

## 編集する場所

- `game.json`: GDevelop のシーン、オブジェクト、イベント。
- `assets/`: キャラクター、マップ素材、効果音など。
- `Overworld`: マップ、移動、会話の編集から始めるシーン。
- `Battle`: 戦闘の土台。
- `THIRD_PARTY_NOTICES.md`: 元サンプルと利用条件。

まず小さな町と草むらを作り、その後にモンスターの捕獲・育成・セーブを追加します。
プロジェクトの編集は GDevelop のイベントエディターを基本にしてください。

## PC 向け出力

GDevelop のエクスポート機能で対象の PC を選びます。
クラウドビルドにはプランや回数の制限があるため、その時点の無料枠を確認してください。
手動ビルドを選ぶ場合は追加ツールが必要です。この初期設定では導入していません。
生成物は `builds/` または `exports/` に保存してください。
